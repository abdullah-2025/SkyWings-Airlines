# SkyWings Airlines Flight Booking

SkyWings Airlines is a university assignment prototype built with ASP.NET Web Forms, C#, and .NET Framework 4.8. It collects passenger details, a flight class, a seat, and optional services. A valid submission is summarized in a safely encoded JavaScript `alert()`.

This application demonstrates a booking workflow only. It does not create a real reservation, take payment, store data, or contact an airline service.

## Features

- Responsive, airline-inspired booking interface
- Exactly three passenger `TextBox` controls
- One grouped choice among Economy, Business, and First Class
- One seat `ListBox` with four available options
- Three independently selectable additional services
- Server-side required-field and email-format validation
- JavaScript-safe booking summary generated by C# code-behind
- No database or external dependencies

## Run the application

Open `SkyWingsAirlines.sln` in Visual Studio 2022 on Windows, restore/build the solution, and run it with IIS Express. `Booking.aspx` is configured as the default document. See [SETUP.md](SETUP.md) for full prerequisites and troubleshooting.
